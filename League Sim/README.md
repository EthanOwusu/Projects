## Overview
This project implements a Python-based simulation of the first 15 minutes of a League of Legends match with an AI-controlled opponent. The notebook focuses on simulation logic and implementation rather than explanatory commentary.

## Notes
The notebook contains the full training output from multiple simulation iterations. While this produces a long output section on GitHub, the core simulation logic is located near the top and bottom of the notebook.
